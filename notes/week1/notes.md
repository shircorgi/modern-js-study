# 1주차 학습 노트

## 1. alert(), confirm(), prompt()
- **alert()**: 알림창
- **confirm()**: 확인/취소 버튼있음 -> 어떤 버튼을 눌렀느냐에 따라 서로 다른 값을 반환
- **prompt()**: 사용자가 값 입력 (기본값을 지정하지 않으면 입력창이 빈칸으로 나옴)
 -- prompt(내용, 기본값) -> 입력창에 '기본값'이 나옴 

## 2. 변수부터 익히기
**변수(variable)**: 값을 담아놓는 바구니 (`let` 을 사용)
- 숫자로 시작 못함. 이름 안에 공백도 안됨. (⭕️ current, _current, $current / ❌ 25current, cur rent, current*)
- 영어의 대/소문자를 구별함. current / Current / CURRENT 다 다른 변수명들임. 
- 한 단어는 소문자, 두 단어 이상부터는 언더바(_) 나 중간에 대문자를 씀. (total_count || totalCount)
- let 같은건 사용불가함. (이미 js에서 쓰는 예약어라서)
- 무의미한 변수이름은 지양함 

**상수(constant)**: 값이 바뀌지 않는 변수 (`const` 를 사용)
- 동일한 값을 여러번 사용할 경우, 상수에다 값을 할당

**재선언과 재할당**
- 위에서 이미 선언을 했어도, 아래에서 재선언을 하면 새로운 값이 재할당 됨

## 3. 자료형
**자료형**: 이 데이터가 어떤 종류의 값인지를 나타내는 것
- 20 = 숫자 / "20" = 문자 
- 원시유형 / 객체로 나뉨
 -- 원시유형: 숫자, 문자열, undefined, null, symbol (하나의 값만 저장하는 자료형)
 -- 객체: 그 외 

**typeof()**: 소괄호 안에 변수를 넣으면 어떤 자료형인지 알려줌

**undefined / null**
- undefined: 변수 선언 ⭕️ / 할당 ❌  (`값이 아직 안 정해짐`)
- null: 변수 선언 ⭕️ / 할당 ⭕️  (`값이 없다고 내가 정해놓음`)

**객체**: 하나의 변수에 여러 정보가 포함된 자료형 
- `({})` 안에 정보를 담음 
- `키 : 값, 키 : 값, ...` 여러개의 키와 값을 , 로 구분 

**배열**
- `배열명 = [값, 값, 값, ...]` 의 형태 
- 배열명 안에 4개의 값을 넣었을 때, 0~3까지의 배열값이 나열됨 
- 배열된 값들의 순서값이 `index` 
- 배열에 몇 개의 값이 있는지 알고 싶다면 `length`프로퍼티 사용 

**심벌**: `Symbol()`
- 유일성을 보장
- 객체 프로퍼티의 키로 사용가능
- 괄호 안에 설명도 추가 가능

## 4. 자료형 변환 
- C언어나 자바에서는 변수의 자료형을 먼저 결정 (강력한 자료형: 프로그램의 오류를 방지)
- 반면, 자바스크립트는 미리 자료형을 지정하지 않음 (느슨한 자료형: 값을 할당하면 그에 따라 결정)
  -- 연산을 위해 자료형이 자동으로 바뀜 
  -- one = "20" (문자열) / two = 10 (숫자형) 일 경우, one `+` two = "2010" 이 됨 
  -- `+` 는 문자+숫자 일 경우, 연결 연산자가 됨 / 반면 `-``*``%` 는 연산에 사용되는걸로 인식 

## 5. 직접 변환하기

### 숫자형으로 변환하기
**Number() 함수**
- () 소괄호 안에 값을 넣어주면 숫자로 변환 
- null / undefined 를 포함하여 모든 자료형을 숫자로 변환

**parseInt() 함수 / parseFloat() 함수**
- `parseInt()`: () 소괄호 안의 값을 정수로 변환
- `parseFloat()`: () 소괄호 안의 값을 실수로 변환 
- 프롬프트 창은 text 필드라서, 입력한 내용은 문자열로 취급됨 
  -- 따라서 입력값을 숫자로 변환해야 함 (예시: `parseInt(userInput)`)

### 문자형으로 변환하기
**toString() 함수**
- null / undefined 를 제외한 나머지를 문자열로 변환 
- `값.toString()` 이 기본형
- num = 10 / num.toString(2) << 여기서 (2) 는 2진수 문자열로 사용가능 

**String() 함수**
- null / undefined 를 포함하여 문자열로 변환
- `String(값)` 이 기본형

### 논리형으로 변환하기
**Boolean() 함수**
- 다른 유형의 데이터를 논리형 데이터로 변환
- `Boolean(값)` 이 기본형
- 변환할때 일정한 규칙이 있음
  -- 값이 0 이거나 비어있으면 false / 그 외의 값이면 true
  -- undefined 는 false 

## 6. 연산자
**산술 연산자** 수학적 계산에 사용 `+` `-` `*` `/` `%` `++` `--`
**연결 연산자** 문자열과 다른 자료형 or 문자열을 합해서 하나의 문자열로 만듬 `(name + "님, 안녕하세요")` -> 문자열
- 여기서 사용하는 `+` 는 문자열끼리 연결하여 `문자열 연산자` 라고 부름
**할당 연산자** 왼쪽(오른쪽에게 할당받음) / 오른쪽(실행결과)
-  `=` `+=` `=+` `*=` `/=` `%=` 
**비교 연산자** 2개의 값을 비교 / 참과 거짓으로 결과값을 반환
- `==` `===` `!=` `!==` `<` `<=` `>` `>=`
- `==` / `!=` 의 차이: 타입(데이터 유형)까지 보지 않음
- `===` / `!==` 의 차이: 타입(데이터 유형)까지 봄 
**논리 연산자** 참과 거짓을 사용해 조건을 체크
- `!` : NOT 연산자 (피연산자값과 반대의 값)
- `&&` : AND 연산자 (피연산자값이 모두 true일 때만 true)
- `||` : OR 연산자 (피연산자값 중 하나만 true여도 true)

## 7. 조건문 
**if문**
- `if(조건){조건이 true일 때 실행할 명령} false일 시 다음 명령`

**if...else문**
- `if(조건){조건이 true일 때 실행할 명령} else{조건이 false일 때 실행할 명령}`

**if...else if...else**
- `if(조건){조건 1이 맞을떄 실행할 명령} else if{조건 2이 맞을떄 실행할 명령} else{조건이 false일 때 실행할 명령}`

**삼항 연산자** 
- `(조건) ? true일떄 실행할 명령 : false일떄 실행할 멸령`

**switch문**
- `switch (조건) {case1 : 값 break; case2 : 값 break;  case3 : 값 break; ... default : 문장}`

## 8. 반복문
**for문** 내가 반복횟수를 조절
- `for (초깃값; 조건; 증가식) {...}`

**forEach문** 배열의 각 요소를 하나씩 꺼냄
- `배열명.forEach(콜백 함수){...}`
